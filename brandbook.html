01 — Essence

Virtual memory for agents.

CHERRY IS A CONTEXT MARKETPLACE FOR AI AGENTS. It lets developers create, store, package, and securely share specific pieces of context that an agent may need to perform a task, instead of forcing every agent to rediscover or repeatedly send the same information.

Cherry works like virtual memory + a marketplace for AI context: agents keep their working memory small while pulling in specialized, reusable knowledge on demand.
Exchange

Publish Context Packs. Versioned, cited, priced.

Retrieval

Rent by name, inject only what the task needs.

Rental & Yield

Temporary access. Creators earn per retrieval.
